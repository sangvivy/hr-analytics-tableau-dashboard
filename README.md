# HR Analytics Dashboard | Tableau

## Project Overview

This project focuses on analysing Human Resources (HR) data using Tableau to explore workforce composition, employment status, and salary distribution. It transforms employee records into interactive visualisations that make workforce information easier to understand and explore.

The project consists of three dashboards: Overview, Demographics, and Income Analysis.

## Objectives

- Analyse key workforce indicators and employment status.
- Explore employee demographics, including age, gender, and education level.
- Examine salary distribution across relevant employee categories.
- Develop interactive dashboards to communicate HR insights.
- Present workforce information through clear and accessible visualisations.

## Tools and Technologies

- **Tableau Desktop** — Data preparation, calculated fields, visualisation, and dashboard development.
- **Tableau Public** — Publishing and sharing interactive dashboards.
- **GitHub** — Project documentation and portfolio presentation.

## Dataset

The dataset contains employee-level information, including:

- Employee ID
- Gender
- State and city
- Education level
- Birthdate, hire date, and termination date
- Department and job title
- Salary
- Performance rating

The dataset was used to develop calculated fields and visualisations for workforce analysis.

## Dashboards

### 1. Overview

Provides a summary of workforce indicators, including total employees hired, active employees, terminated employees, and the active employee percentage.

**Key metrics:**

| Metric | Value |
|---|---:|
| Total Hired | 8,950 |
| Total Active | 7,984 |

### 2. Demographics

### 3. Income Analysis

Examines salary distribution and comparisons across employee categories, supporting the exploration of compensation patterns within the workforce.

## Methodology

1. Imported the HR dataset into Tableau Desktop.
2. Reviewed the available fields and prepared the data for analysis.
3. Created calculated fields, including age, age groups, and employment status.
4. Developed individual worksheets to explore workforce patterns.
5. Organised the visualisations into three dashboards.
6. Applied formatting and navigation to improve dashboard usability.
7. Published the workbook to Tableau Public.

## Key Insights

The Overview dashboard reports 7,984 active employees out of 8,950 employees counted, corresponding to an active employee percentage of 89.21%.

The Demographics dashboard supports comparisons across employee groups, while the Income Analysis dashboard provides a visual basis for exploring salary distribution.

These dashboards support workforce reporting and further investigation of HR patterns. Specific demographic and salary conclusions should be drawn from the corresponding visualisations.
